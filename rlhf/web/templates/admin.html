Trening uruchamia się automatycznie po zebraniu ≥ {{ settings.training_threshold }} nowych rozstrzygających adnotacji (wybór A/B) od ostatniej próby treningu. Koordynator monitoruje tę wartość w tle i uruchamia pełny potok (trening modelu nagrody → opcjonalne SFT → generowanie danych DPO → DPO z ewaluacją).
Adnotowanie pozostaje dostępne w trakcie treningu. Auto-training fires when ≥ {{ settings.training_threshold }} new actionable (a/b preference) annotations accumulate since the last training attempt. The coordinator service monitors this in the background and runs the full pipeline (train reward → score pairs → optional SFT → DPO with evaluation).
Annotation remains fully available during training.
